# Contracts

`contracts/` holds the HTTP API's definition (`api/`: paths, zod schemas, versions, quotas and the OpenAPI document), the MCP server's identity and tool catalogue (`mcp.ts`), the chat widget's wire protocol (`chat.ts`) and the R2 key for blog audio (`audio.ts`). The Worker serves these, `/developers/` and the chat widget render from them, and the audio scripts write to them. Contracts hold only shapes: zod schemas, types and constants. Both `check:src` and `check:worker` type-check them, so a contract that reaches for `Env` or a Worker binding fails the site's check, and lint rejects value imports from framework, AI SDK and `node:` packages. Type imports are fine.
